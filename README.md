# webext-learning

A learning experiment: building fluency in browser extension development (Firefox + Chrome, Manifest V3) using the personal learning framework I use with Claude Code to structure and track skill-building.

This isn't a project meant to ship anything — it's a workspace for deliberately learning a topic, the real in-progress extension it's anchored around as a running example.

## The framework

Each learning track under this framework follows the same shape:

- **`MISSION.md`** — why this track exists, what "success" looks like, and what's explicitly out of scope.
- **`NOTES.md`** — standing context worth remembering across sessions (constraints, decisions, things not to assume).
- **`RESOURCES.md`** — curated links (docs, communities) with notes on what each is for, plus a running list of known gaps.
- **`lessons/`** — the actual walkthroughs, numbered in the order they were worked through.
- **`experiments/`** — small, working, hands-on builds that accompany each lesson.
- **`reference/`** — cheatsheets and glossaries distilled after the fact, for quick lookup without re-reading a full lesson.
- **`learning-records/`** — dated notes on what was actually learned or discovered in each session, including things that went right on the first try and mistakes that turned into lessons (e.g. Firefox dropping port numbers in match patterns).

The goal of the structure is to make progress legible over time: what's been covered, what was hard, what's still a gap, and where to go next.
